# Project Context

## Nome
RepFlow

## Objetivo

Plataforma para organização de repúblicas universitárias.

## Público-alvo

## Principais problemas que resolve

- Controle de limpeza.
- Comunicação interna.
- Gestão de compras compartilhadas.
- Controle financeiro.
